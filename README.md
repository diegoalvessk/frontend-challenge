# Kurio — Marketplace de NFTs

Solução do [Desafio Frontend da Jungle Gaming](https://github.com/junglegaming/frontend-challenge).

> Em construção. A documentação completa (setup, cenários de mock, contratos REST e eventos) será adicionada ao longo do desenvolvimento.

## Comandos

```bash
npm install
npm run dev        # desenvolvimento com mocks (MSW)
npm run build      # build otimizado
npm run preview    # serve o build
npm run typecheck
npm run lint
```
